# 성경 모바일 웹사이트 (`bible-mobile-web`)

한국어 **개역개정**과 영어 **NIV**를 한 화면에 한 장씩 읽고, 사전 검토된 본문 이해 자료(66권 개관 + 장별 요약·시대 배경·지도/연표·인물 설명·관련 장절)와 브라우저 전용 개인 읽기 기록(책갈피·밑줄)을 제공하는 모바일 최적화 정적 웹 애플리케이션입니다.

## 주요 기능

1. **공용 비밀번호 입장 · 메인 화면 두 읽기 경로 · 이어 읽기**   
   - 인증 성공 후 **메인 화면**에서 **성경순 읽기**(정경 66권 목차)와 **연대순 읽기**(12시대 통합 역사 연대표) 두 경로를 동등하게 선택할 수 있으며, 읽기 기록이 있으면 **이어서 읽기**를 제공합니다.
2. **통합 성경 역사 연대표 및 본문 역사적 배경**
   - 원역사(연대 미확정 · 상대적 순서)부터 족장, 출애굽, 정복·사사, 통일·분열·단독왕국, 포로·귀환, 신구약 중간기(외부 역사 구분), 예수님의 생애, 초대교회·서신 배경까지 비례 시간축(BC/AD 사이 0년 없음)으로 탐색합니다.
   - 인물·왕국·사건 선택 시 시기 성격·정확도·동시대 인물·관련 장절을 확인하고 본문으로 이동하며, 뒤로 가기 시 연대표 스크롤·배율·필터·선택 상태를 복원합니다.
   - 역사적 배경이 검증된 본문에서는 기본 접힘 상태의 **역사적 배경** 패널로 공통 연대표를 바로 펼쳐 볼 수 있습니다(역사 시점을 특정할 수 없는 지혜서 등에는 임의 연대를 표시하지 않음).
3. **모바일 단일 장 읽기**
   - 책·장·절 3단계 바텀시트 즉시 이동 및 이전 장 / 다음 장 이동
   - `개역개정 ↔ NIV` 전환 시 읽던 절 유지 (절 번호 부재 또는 `(없음)` 구절일 경우 차이 안내 및 같은 장 인접 구절 표시)
   - 5단계 글자 크기 조절 시 읽던 절이 화면 위치에 그대로 유지됨
4. **절 단위 본문 탐구 (P0: F01~F04) 및 장 단위 본문 이해**
   - 본문 구절을 탭하면 본문 흐름을 가리지 않는 **인라인 도구 바**(`본문 탐구` · `번역 비교` · `책갈피` · `밑줄` · `복사` · `공유`)가 열리고, `본문 탐구` 선택 시 절 기준 하단 시트(`VerseStudySheet`)가 표시됩니다.
   - **관련 말씀 (관주, F02)**: 단순 어휘 일치 추천을 배제하고, 직접 인용·예언 성취·병행 사건·문맥 연결 등 실제 본문 관계와 구절 실재 여부가 검증(`VERIFIED`)된 구절만 최대 5개까지 구체적 연결 이유와 함께 제공합니다.
   - **문맥 해설 (F03)**: 단락 범위의 화자·청자·시대 상황·앞뒤 흐름·주요 표현 풀이를 본문 명시 사실과 학술적 해석/이견으로 구분해 제공하며, 기존 66권 전체 개관 및 장별 상세 해설·위성 지도와 계층적으로 연결됩니다.
   - **역본 대조 (F04)**: 전 구절(66권 1,189장) 개역개정 ↔ NIV 나란히 비교를 제공하며, 절 번호 밀림(고후 13:11–14, 요삼 1:14–15, 계 12:17–13:1) 및 사본상 `(없음)` 14개 구절·누락 구절(겔 16:63)을 의미 단위로 자동 정렬해 안내합니다.
   - 관련 구절 팝업 미리보기(이어서 읽기 위치 미갱신) → **해당 구절/장 이동** → **원래 본문으로 돌아가기**(출발 번역본·절·스크롤 좌표 복원)
5. **개인 읽기 기록 (`localStorage` 전용) 및 구절 공유**
   - 구절별 **책갈피**와 **밑줄** 개별 추가·해제, 구절 클립보드 **복사** 및 모바일 **공유**
   - **내 기록**에서 책갈피·밑줄 각각 모아 보기 및 저장 당시 번역본·구절로 즉시 이동

## 실행 및 검증 명령

```bash
# 1. 성경(.lfa) 변환 + 장별 해설 검증 + 본문 탐구 검증 + 역사 연대표 검증 빌드
npm run data:build
# (역사 연대표 데이터만 단독 검증·빌드할 때: npm run data:history)

# 2. 데이터 파이프라인(Python) + 웹앱 요구사항·P0 탐구(Vitest) 전체 테스트 실행
npm run test:all

# 3. 로컬 개발 서버 실행
npm run dev

# 4. 정적 배포용 프로덕션 빌드 (dist/ 생성)
npm run build
```
